## 1. 교육 개요 및 설계 방향

### 1.1 교육 배경 및 목표
본 과정은 제조 대기업의 비개발직군(전략기획·재무·마케팅·세일즈) 과장급 AX 핵심인재 20명을 대상으로, 단순 프롬프트 질의응답을 넘어 **자신의 현업 문제를 해결하는 실동작 업무용 웹 도구(MVP)를 직접 설계·구현·검증** 하는 실전형 PBL(Project-Based Learning) 과정입니다.

- **선행 학습 연계**: 사전 1일차 교육을 통해 완료된 `Claude Code 데스크톱 세팅`, `바이브코딩 기본 흐름 이해`, `개인별 과제 기획서 초안`을 바탕으로, 본 과정(14시간)에서는 **즉시 구현 가능한 수준의 과제 범위 축소(Scoping) → 핵심 기능 1~2개 집중 개발 → 실제 데이터 연동 및 디버깅 → 현업 도입 시연** 으로 직결되도록 재설계하였습니다.
- **비전공자 및 보안 환경 최적화**: 사내 보안 정책이 적용된 Windows 업무용 PC 환경과 실데이터 외부 반출 제약을 고려하여, **별도 서버/DB 구축 없이 브라우저에서 즉시 동작하는 단일 폴더 로컬 웹앱(HTML/JS/CSS + CSV/Excel 파서) 및 Google Colab 기반 아키텍처** 를 표준 스택으로 채택합니다.

### 1.3 5대 핵심 학습 성과 (Learning Outcomes)
1. **문제 정의 (Problem Framing)**: 현업의 반복적 수작업·엑셀 집계·보고서 작성 업무를 AI 개발 과제로 구조화한다.
2. **범위 및 설계 (MVP Scoping)**: 과도한 기능을 덜어내고 2주 내에 완주 가능한 **핵심 기능 1~2개** 와 입출력 데이터 구조를 정의한다.
3. **바이브코딩 구현 (Iterative Building)**: `CLAUDE.md`와 Plan 모드를 활용하여 Claude Code에 단계별로 명확한 작업 지시를 내리고 기능을 구현한다.
4. **AI 협력 디버깅 (Debugging & Verification)**: 에러 메시지·화면 깨짐·데이터 계산 오류를 발견하고, 재현 조건을 명시하여 AI와 함께 해결한다.
5. **업무 적용 및 확산 (AX Impact)**: 개발한 MVP의 정량·정성적 효과(시간 절감, 휴먼 에러 감소)를 입증하고 부서 내 확산 로드맵을 수립한다.

## 4. 직무별 권장 MVP 프로젝트 아키텍처 (4대 직무)

비전공자 과장급 인력이 14시간 내에 높은 완성도로 구현할 수 있도록 **단일 폴더 웹 애플리케이션(HTML5 + TailwindCSS CDN + Chart.js + PapaParse CSV 파서)** 또는 **Google Colab 대화형 대시보드** 를 표준 템플릿으로 제공합니다.

### ① 전략기획 직무: 경영 KPI 달성률 & 전사 실적 브리핑 대시보드
- **해결하려는 현업 문제**: 매월 사업부별 실적 엑셀을 취합해 목표 대비 달성률과 전월/전년 대비 증감을 계산하고 임원 보고용 요약 코멘트를 작성하는 데 1~2일 소요
- **핵심 기능 (2개)**:
  1. 사업부별 월간 실적 CSV 업로드 시 매출·영업이익·달성률 자동 집계 및 신호등(정상/주의/위험) 시각화
  2. 미달성 핵심 지표 자동 추출 및 임원 보고용 3줄 요약 브리핑 문구 자동 생성/복사

### ② 재무/회계 직무: 부서별 예산 대비 실적(BVA) 편차 분석 및 이상 탐지기
- **해결하려는 현업 문제**: 수백 행의 계정과목별 예산·실집행 내역을 대조하여 초과 집행 항목과 급증 원인을 수작업으로 필터링하는 비효율
- **핵심 기능 (2개)**:
  1. 예산/실적 CSV 업로드 시 계정별 편차 금액·소진율 자동 계산 및 허용 임계치(예: 100% 초과, 전월비 30% 급증) 초과 항목 자동 하이라이트
  2. 부서별·계정별 필터링 및 소명 요청 대상 리스트 원클릭 다운로드(CSV/인쇄 보고서)

### ③ 마케팅 직무: 채널별 캠페인 ROI 비교 및 예산 재배분 시뮬레이터
- **해결하려는 현업 문제**: 매체별(검색, SNS, 배너, 전시회)로 흩어진 광고비·노출·클릭·전환 데이터를 통합하여 CAC(고객획득비용)와 ROAS를 비교하기 번거로움
- **핵심 기능 (2개)**:
  1. 캠페인 성과 데이터 입력/업로드 시 채널별 CTR, CVR, CPA, ROAS 자동 산출 및 효율 순위 차트 생성
  2. 슬라이더로 차월 채널별 예산 비중 조정 시 예상 전환수 및 매출 변화를 즉시 계산하는 시뮬레이터

### ④ 세일즈/영업관리 직무: B2B 제조 제품 스마트 견적 산출 및 마진 검증기
- **해결하려는 현업 문제**: 고객사별 수량 할인율, 원자재 옵션, 물류비에 따라 영업사원마다 견적 단가와 마진율 계산이 달라지거나 승인 기준 이하 견적이 발행되는 문제
- **핵심 기능 (2개)**:
  1. 품목·수량·할인율·납기 조건 선택 시 권장 판가, 원가, 예상 마진율(%) 자동 계산 및 최소 마진 가이드라인 미달 시 즉시 경고 표시
  2. 고객사 제출용 표준 견적서(인쇄/PDF 저장용 클린 뷰) 원클릭 생성

## 5. 주강사 코칭 및 프로젝트 운영 전략

### 5.1 조별 순회 코칭 운영안 (5개 조 × 4명 = 20명)
- **조 편성 원칙**: 직무 유사성(①전략기획조 ②재무조 ③마케팅조 ④세일즈A조 ⑤세일즈B/혼합조)을 기준으로 4인 1조 편성 → 동일한 데이터 구조와 도메인 고민을 공유하여 동료 학습(Peer Learning) 극대화
- **10분 타임박싱(Time-boxing) 순회 코칭 프로토콜**:
  - **도입 2분**: 조원 4명의 현재 화면 상태 및 막힌 지점 동시 스캔
  - **공통 처방 5분**: 조 내 공통 이슈(예: CSV 칼럼 인식, 수식 계산 오류)를 대표 1인의 화면에서 Claude Code로 시연하며 해결
  - **개별 처방 3분**: 과도한 기능 욕심(예: 로그인, DB 구축, 사내 ERP API 직결)을 덜어내고 당일 완성할 핵심 기능 1개로 스코프 확정

### 5.2 프로젝트 기간 중 Q&A 채널 및 추가 온라인 코칭 운영
- **상시 Q&A 채널 대응 (11/2 ~ 11/13)**:
  - 교육생이 질문할 때 **"① 하고자 한 작업 ② 입력한 프롬프트 ③ 발생한 오류 화면 캡처"** 3가지를 올리도록 표준 질문 양식 배포 → 신속·정확한 원격 트러블슈팅 제공
- **온라인 코칭 데이 운영안 (11/2~11/9 중 1일 추가 시)**:
  - 이론 강의 없이 **그룹 클리닉(Group Clinic)** 방식으로 운영
  - 사전 설문으로 미진척자 및 고난도 이슈 보유자를 파악하여 화면 공유 기반 라이브 디버깅 및 DAY 2 멘토링 우선순위 확정

### 5.3 제조 대기업 보안 및 실습 환경 대응 방안
1. **데이터 보안 원칙**: 사내 실데이터(기밀 재무 수치, 실제 고객명 등) 사용을 엄격히 금지하며, Claude에게 "기존 엑셀 헤더 구조만 유지하고 숫자와 명칭은 가상의 샘플 데이터 50행으로 생성해줘"라고 지시하여 **100% 합성 샘플 데이터(Synthetic Data)** 로 개발 및 시연을 진행합니다.
2. **Windows 업무용 PC 제약 대응**: 별도 런타임 설치가 막혀 있는 경우에도 100% 동작하도록 **브라우저 내장 실행(Vanilla HTML/JS + 검증된 CDN)** 방식을 기본으로 채택하고, 데이터 분석 중심 과제는 허용된 **Google Colab + Google Drive** 환경에서 구현하도록 이원화 가이드를 제공합니다.

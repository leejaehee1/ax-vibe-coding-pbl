# 프로젝트명: 영업 실적 분석 대시보드 (DAY 1 공통 실습 예제)

## 1. 목적 및 대상
- 대상: 제조 대기업 비개발 직군 실무자 (DAY 1 실습 데모용)
- 목적: 월별·지역별·제품군별 영업 실적 CSV를 업로드하면 달성률과 추이를 즉시 시각화하고 요약 브리핑을 생성하는 로컬 웹 도구

## 2. 기술 제약사항
- 서버/DB 없이 브라우저에서 `index.html` 단독 실행
- 내장 샘플 데이터 기본 탑재 + CSV 파일 업로드(UTF-8/EUC-KR 호환) 지원
- 핵심 기능 1: 목표 대비 달성률(%) 자동 계산 및 미달성(90% 미만) 경고 표시
- 핵심 기능 2: 지역본부/제품군 필터링 및 임원 보고용 3줄 요약 자동 생성

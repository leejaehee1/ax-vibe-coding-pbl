# [필수 가이드 0] 보안 정책 적용 Windows 업무용 PC 실전 세팅 매뉴얼

> **작성 목적**: 교육장 내 **Windows 업무용 PC (Mac 사용 불가, 사내 보안 정책 적용)** 환경에서 강사와 수강생(비전공자 20명)이 막힘없이 **Claude Code · 로컬 웹앱 · Google Colab · Cloudflare** 실습을 진행할 수 있도록 단계별 세팅 절차와 비상 우회 방법(Fallback)을 정리한 매뉴얼입니다.

## 1. [강사용] 교육 시작 30분 전 교탁 Windows PC 세팅 (5분 체크리스트)

교육장 도착 직후 강사용 Windows PC(또는 지참한 Windows 노트북)에서 아래 5단계를 순서대로 진행합니다.

### Step 1. 교육 포털 접속 및 전체 자료 일괄 다운로드
1. 크롬(Chrome) 또는 엣지(Edge) 브라우저를 열고 아래 교육 포털 주소로 접속합니다.
   - **교육 포털**: https://leejaehee1.github.io/ax-vibe-coding-pbl/
   - **GitHub 저장소**: https://github.com/leejaehee1/ax-vibe-coding-pbl
2. GitHub 저장소 우측 상단 초록색 **`<> Code`** 버튼 → **`Download ZIP`** 클릭 후 바탕화면(`C:\AX_Lecture`)에 압축을 풉니다.
3. 인터넷이 일시적으로 불안정하더라도 압축 해제한 폴더 내 `02_강의교안_PPTX/`와 `04_직무별_실습예제_MVP_및_샘플데이터/`만으로 100% 오프라인 강의 및 시연이 가능합니다.

### Step 2. 프로젝터 화면 및 Windows 탐색기 설정
1. **화면 배율 조정**: 바탕화면 우클릭 → `디스플레이 설정` → 배율을 **125% 또는 150%** 로 설정 (뒤쪽 좌석에서도 터미널 글씨와 표가 선명하게 보이도록 조정).
2. **파일 확장자 표시 켜기 (매우 중요)**:
   - `Win + E` (파일 탐색기 실행) → 상단 메뉴 **`보기(View)`** → **`표시(Show)`** → **`파일 이름 확장자(File name extensions)` 체크**
   - (주의: 이 설정이 꺼져 있으면 수강생이 `CLAUDE.md`나 `index.html`을 만들 때 실제로는 `CLAUDE.md.txt`, `index.html.txt`로 저장되어 실행되지 않습니다.)

## 2. [수강생 공통] Windows PC 초기 작업 환경 세팅 (10분)

1일차에 기본 세팅이 완료되었더라도, 본 교육(DAY 1) 시작 시 아래 **3가지 황금 규칙** 을 반드시 먼저 확인합니다.

### 규칙 ① 한글·공백·OneDrive가 없는 전용 작업 폴더 생성
Windows 보안 PC에서는 `바탕화면`이나 `문서` 폴더가 사내 **OneDrive / 보안 문서중앙화** 와 실시간 동기화되면서 파일 잠김이나 한글 경로 오류가 자주 발생합니다.

1. 파일 탐색기(`Win + E`)를 열고 **`로컬 디스크 (C:)`** 최상단으로 이동합니다.
2. 새 폴더를 만들고 이름을 **`C:\ax_mvp`** (영문 소문자, 공백 없음)로 지정합니다.
3. 그 안에 본인 과제용 하위 폴더(예: `C:\ax_mvp\finance_bva`)를 생성합니다.

### 규칙 ② 파일 이름 확장자 표시 활성화
- **Windows 11**: 탐색기 상단 `보기` → `표시` → **`파일 이름 확장자` 체크**
- **Windows 10**: 탐색기 상단 `보기` 탭 → 우측 **`파일 이름 확장명` 체크박스 선택**

### 규칙 ③ 기본 웹 브라우저(Chrome 또는 Edge) 및 텍스트 편집기 확인
- 완성된 `index.html` 파일을 우클릭 → `연결 프로그램` → **Google Chrome** 또는 **Microsoft Edge** 로 열리는지 확인합니다.
- 코드를 직접 열어볼 때는 Windows 기본 **메모장(Notepad)** 또는 설치되어 있다면 **VS Code** 를 사용합니다.

## 3. Claude Code 실행 및 연동 세팅 (환경별 3가지 방식)

교육장 PC의 1일차 세팅 형태(데스크톱 앱 방식 vs 터미널 CLI 방식)에 따라 아래 해당 방식을 선택해 실행합니다.

### 방식 A. Claude Desktop 앱 (Claude Code 내장 탭 / 로컬 폴더 연동)
1. Windows 시작 메뉴에서 **Claude** 데스크톱 앱을 실행하고 지급받은 **Claude Team 계정** 으로 로그인합니다.
2. 앱 내 **Claude Code (또는 프로젝트/로컬 폴더 연동 메뉴)** 를 선택합니다.
3. 작업 대상 디렉터리(Working Directory)를 방금 만든 **`C:\ax_mvp\내과제폴더`** 로 지정합니다.
4. 채팅창에 아래 테스트 명령을 입력하여 폴더 연결을 확인합니다.
   ```text
   현재 폴더에 있는 파일 목록을 확인하고, 테스트용으로 hello.txt 파일을 만들어줘.
   ```

### 방식 B. Windows PowerShell / 명령 프롬프트(CMD) 터미널에서 실행
1. 파일 탐색기에서 `C:\ax_mvp\내과제폴더`로 이동한 뒤, 상단 주소창에 **`cmd`** 또는 **`powershell`** 을 입력하고 `Enter`를 누릅니다 (해당 폴더 위치에서 바로 터미널이 열립니다).
2. 터미널에 아래 명령어를 입력해 Claude Code를 실행합니다.
   ```powershell
   claude
   ```
3. **[자주 발생하는 Windows PowerShell 보안 오류 해결]**:
   - 만약 PowerShell에서 `이 시스템에서 스크립트를 실행할 수 없으므로... (PSSecurityException)` 빨간 글씨 오류가 뜬다면, 아래 명령어를 복사해 붙여넣고 `Enter`를 누르면 즉시 해결됩니다.
   ```powershell
   Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force
   ```
   - 또는 PowerShell 대신 **명령 프롬프트(`cmd.exe`)** 창을 열어서 `claude`를 입력하면 실행 정책 제한 없이 바로 실행됩니다.

### 단축키 및 핵심 명령어 (Windows 기준)
| 기능 | Windows 키 조작 / 명령어 | 용도 |
| :--- | :--- | :--- |
| **Plan 모드 전환** | **`Shift + Tab`** (입력창에서) | 코드를 바로 짜지 않고 개발 계획부터 먼저 세울 때 |
| **프로젝트 초기화** | `/init` | 현재 폴더 구조를 분석해 기본 `CLAUDE.md` 생성 |
| **대화 맥락 압축** | `/compact` | 대화가 길어졌을 때 핵심만 남기고 속도 회복 |
| **새 작업 시작** | `/clear` | 이전 대화 기록을 비우고 새로운 지시 시작 |
| **작업 강제 중단** | **`Ctrl + C`** 또는 **`Esc`** | AI가 의도와 다른 코드를 길게 작성 중일 때 즉시 멈춤 |

## 4. Windows 엑셀 & CSV 한글 깨짐 완벽 방지 세팅

제조 대기업 실무자는 대부분 데이터를 **Microsoft Excel** 로 관리합니다. Windows 엑셀에서 CSV를 저장할 때 아래 방법만 지키면 한글 깨짐이 100% 사라집니다.

### 방법 1. 엑셀에서 저장할 때 `CSV UTF-8` 선택 (권장)
1. 엑셀에서 샘플 데이터를 정리한 뒤 `파일` → `다른 이름으로 저장`을 클릭합니다.
2. 파일 형식 드롭다운에서 일반 `CSV(쉼표로 분리)` 대신 반드시 위에 있는 **`CSV UTF-8(쉼표로 분리)(*.csv)`** 를 선택하여 저장합니다.

### 방법 2. 이미 깨진 CSV 파일을 메모장으로 10초 만에 고치기
1. 한글이 깨지는 `.csv` 파일을 우클릭 → `연결 프로그램` → **메모장(Notepad)** 으로 엽니다.
2. `파일` → `다른 이름으로 저장` 클릭 후, 저장 버튼 옆 **인코딩(Encoding)** 을 **`UTF-8(BOM)`** 또는 **`UTF-8`** 로 바꾸어 덮어씁니다.

### 방법 3. Claude Code에게 자동 인코딩 감지 코드 넣기 (근본 해결)
- 프롬프트에 아래 한 줄만 추가하면 어떤 엑셀 파일을 올려도 웹앱이 알아서 읽습니다.
  ```text
  파일 업로드 시 TextDecoder('utf-8')로 먼저 읽고, 깨짐 문자(\uFFFD)가 있으면 자동으로 TextDecoder('euc-kr')로 다시 읽도록 구현해줘.
  ```

## 5. [비상 대안] 사내 보안으로 로컬 실행이 막혔을 때 (Google Colab & Cloudflare)

만약 특정 수강생의 PC에서 보안 프로그램(DRM/백신) 때문에 로컬 파일 제어에 제약이 발생하면, 허용된 **Google Colab** 또는 **Cloudflare** 로 즉시 전환합니다.

### 대안 A. Google Colab + Google Drive 활용 (파이썬 데이터 분석·대시보드)
1. 브라우저에서 https://colab.research.google.com 접속 후 새 노트북(`New Notebook`)을 생성합니다.
2. 좌측 폴더 아이콘 클릭 → `sample.csv` 파일을 드래그 앤 드롭으로 업로드합니다.
3. Claude에게 받은 파이썬 분석/시각화 코드를 셀에 붙여넣고 **`Shift + Enter`** 를 누르면 별도 프로그램 설치 없이 차트와 분석 결과표가 즉시 출력됩니다.

### 대안 B. Cloudflare Pages 무설치 웹 배포 (선택 사항 · 보안 승인 시)
명령어(CLI) 설치 없이 웹 브라우저에서 마우스 드래그만으로 내 MVP를 사내 동료에게 링크로 공유하는 방법입니다.
1. https://dash.cloudflare.com 로그인 → 좌측 메뉴 **`Workers & Pages`** 클릭
2. **`Create`** → **`Pages`** 탭 선택 → **`Upload assets`** (직접 업로드) 클릭
3. 프로젝트 이름(예: `my-ax-mvp`) 입력 후, 내 `index.html`과 `sample.csv`가 들어있는 **`C:\ax_mvp\내과제폴더`** 를 마우스로 드래그 앤 드롭하고 **`Deploy site`** 를 클릭합니다.
4. 10초 만에 `https://my-ax-mvp.pages.dev` 주소가 생성되어 발표장 PC나 동료 PC에서 즉시 접속할 수 있습니다. (※ 반드시 100% 가명 샘플 데이터만 포함된 상태에서 진행합니다.)

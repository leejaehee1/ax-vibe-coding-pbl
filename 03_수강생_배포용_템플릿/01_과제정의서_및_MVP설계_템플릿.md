## 2. 현업 문제 정의 (As-Is vs To-Be)

### 2.1 현재 업무의 불편함 (Pain Point / As-Is)
- **누가, 언제, 어떤 작업을 하는가?**: *(예: 매월 초 마감 후, 15개 부서의 예산 대비 실집행 엑셀 파일(약 500행)을 취합하여 계정별 증감액과 소진율을 수작업 수식으로 계산함)*
- **현재 소요 시간 및 주요 문제점**: *(예: 매월 약 6시간 소요, 부서별 양식 차이 및 수식 복사 실수로 인한 집계 오류 발생)*

### 2.2 MVP 도입 후 변화된 모습 (To-Be)
- **어떻게 바뀌는가?**: *(예: CSV 파일을 드래그 앤 드롭하면 5초 만에 부서별·계정별 편차 표와 초과 집행 경고 카드가 화면에 표시됨)*
- **기대 효과 (정량/정성)**: *(예: 월간 작업 시간 6시간 → 15분으로 95% 단축, 이상 지출 항목 누락 제로화)*

## 3. 데이터 입·출력 명세 (Input → Process → Output)
> **⚠️ 보안 필수 원칙**: 사내 실제 기밀 데이터는 절대 사용하지 않습니다. 실제 엑셀의 **컬럼명(헤더) 구조만 참고**하여 가상의 샘플 데이터(CSV)로 작성합니다.

| 구분 | 상세 내용 |
| :--- | :--- |
| **① 입력 데이터 (Input)** | • **파일 형식**: CSV 파일 업로드 또는 화면 입력 폼<br>• **주요 컬럼(열) 구성**: *(예: `연월`, `부서명`, `계정과목`, `예산액`, `실집행액`, `전월집행액`, `담당자`)* |
| **② 핵심 처리 로직 (Process)** | • **계산 수식 1**: *(예: `편차금액 = 실집행액 - 예산액`, `소진율(%) = (실집행액 / 예산액) × 100`)*<br>• **판정 규칙 2**: *(예: 소진율 100% 초과 시 '위험(적색)', 90% 이상 시 '주의(황색)', 그 외 '정상(녹색)' 표시)* |
| **③ 출력 결과 (Output)** | • **상단 요약 카드**: *(예: 총예산, 총실적, 전체 소진율, 초과 계정 건수 4개 카드)*<br>• **시각화 차트**: *(예: 부서별 예산 대비 실적 막대그래프 1개)*<br>• **상세 표 & 다운로드**: *(예: 초과 항목 필터링 테이블 및 결과 CSV 다운로드 버튼)* |

## 4. MVP 기능 범위 설정 (핵심 기능 1~2개 집중)
> **💡 스코핑(Scoping) 원칙**: "있으면 좋은 기능"은 과감히 버리고, **이 도구의 존재 이유를 증명하는 핵심 기능 1~2개(Must-Have)**만 이번 교육에서 구현합니다.

| 우선순위 | 기능 구분 | 기능 상세 설명 | 이번 교육 구현 여부 |
| :---: | :--- | :--- | :---: |
| **핵심 1 (Must)** | 데이터 업로드 및 자동 계산 표 | CSV 파일을 업로드하면 예산 편차와 소진율을 자동 계산하여 표와 요약 카드로 표시 | **✅ 구현 (DAY 1)** |
| **핵심 2 (Must)** | 이상 항목 필터링 및 리포트 출력 | 초과 집행(100% 이상) 항목만 원클릭 필터링하고 부서별 차트 및 요약 보고서 출력 | **✅ 구현 (DAY 2)** |
| *보류 (Later)* | *사내 ERP/SAP 실시간 API 연동* | *보안 및 IT 부서 협의 필요 사항으로 로컬 파일 업로드 방식으로 대체* | *❌ 제외 (향후 과제)* |
| *보류 (Later)* | *임직원 로그인 및 권한 관리* | *단일 사용자 로컬 웹앱이므로 로그인 기능 생략* | *❌ 제외 (향후 과제)* |

## 6. MVP 성공 기준 (Acceptance Criteria)
1. [ ] 샘플 CSV 파일(30행 이상)을 업로드했을 때 에러 없이 표와 요약 숫자가 즉시 계산되는가?
2. [ ] 핵심 기능 1~2개(예: 필터링, 계산, 차트 표시)가 의도한 수식대로 정확히 동작하는가?
3. [ ] 처음 보는 부서 동료가 설명 없이도 1분 안에 사용법을 이해할 수 있는가?

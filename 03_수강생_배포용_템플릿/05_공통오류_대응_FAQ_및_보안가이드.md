## Part 1. 제조 대기업 보안 및 데이터 사용 필수 수칙 (3대 원칙)

### 원칙 1. 사내 실데이터(기밀 수치, 실명, 거래처명) 업로드 절대 금지
- 사내 ERP/MES/회계 시스템에서 추출한 원본 엑셀 파일을 그대로 AI에 입력하지 마세요.
- **안전한 변환 방법**: 원본 엑셀의 **1행(컬럼 제목)만 복사**한 뒤, Claude Code에 다음과 같이 지시합니다.
  > *"우리 부서 엑셀 컬럼은 `[연월, 사업부, 거래처코드, 품목군, 수량, 단가, 매출액, 원가]`로 구성되어 있어. 실제 데이터 없이 이 컬럼 구조에 맞는 가상의 제조기업 샘플 데이터 40행을 `sample_data.csv`로 만들어줘."*

### 원칙 2. 외부 무분별 배포 지양 및 로컬 실행 우선
- 본 과정에서 제작하는 MVP는 기본적으로 **내 PC 브라우저에서 인터넷 서버 없이 돌아가는 로컬 웹앱(`index.html`)** 형태로 작동합니다.
- Cloudflare 등을 통한 외부 URL 배포는 가명 샘플 데이터만 포함된 상태에서 교육장 내 보안 승인 범위 안에서만 선택적으로 진행합니다.

### 원칙 3. 사내 네트워크/방화벽 제약 우회 금지
- 패키지 설치(`npm install`, `pip install`)가 사내 보안 정책으로 차단된 경우, 무리하게 우회하지 말고 **브라우저 기본 내장 기능(Vanilla HTML/JS) 또는 승인된 Google Colab 환경**으로 전환하도록 Claude에게 지시합니다.

## Part 2. 자주 발생하는 공통 오류 Top 6 및 해결 프롬프트

### Q1. 엑셀에서 저장한 CSV 파일을 올렸더니 한글이 `???` 또는 외계어(``)로 깨져요!
- **원인**: Windows 엑셀에서 기본 저장한 CSV는 `CP949(EUC-KR)` 인코딩을 사용하는 반면, 웹 브라우저는 기본으로 `UTF-8`을 읽기 때문입니다.
- **Claude Code 해결 지시문**:
  ```text
  Windows 엑셀에서 저장한 CSV 파일(EUC-KR/CP949 인코딩)을 업로드할 때 한글이 깨집니다.
  파일을 읽을 때 `TextDecoder('utf-8')`로 먼저 확인하고, 깨짐 문자가 있으면 자동으로 `TextDecoder('euc-kr')`로 다시 읽도록 파일 업로드 코드를 수정해 주세요.
  ```

### Q2. `index.html`을 더블클릭해서 열었더니 기본 `sample.csv`가 자동으로 안 불러와져요! (CORS 오류)
- **원인**: 브라우저 보안 정책상 로컬 파일(`file://`) 상태에서는 같은 폴더의 외부 `.csv` 파일을 `fetch()`로 자동 로드하는 것이 차단됩니다.
- **Claude Code 해결 지시문**:
  ```text
  로컬에서 `index.html`을 직접 더블클릭해 열면 CORS 보안 정책 때문에 `sample.csv`를 자동 fetch하지 못합니다.
  1) 기본 샘플 데이터 30행은 자바스크립트 변수(배열 또는 CSV 문자열)로 `index.html` 코드 내부에 함께 내장해서, 페이지를 열자마자 바로 대시보드가 보이게 해주세요.
  2) 동시에 상단 `<input type="file">` 버튼으로 외부 `sample.csv` 파일도 직접 선택해 업로드할 수 있도록 유지해 주세요.
  ```

### Q3. 합계나 달성률이 숫자가 아니라 `NaN` 또는 `Infinity%`로 나와요!
- **원인**: CSV 숫자에 천 단위 콤마(`1,200,000`), 공백, 원화 기호(`₩`)가 포함되어 문자열로 인식되었거나, 분모(목표액/예산액)가 `0`인 행이 있기 때문입니다.
- **Claude Code 해결 지시문**:
  ```text
  계산 결과에 `NaN`과 `Infinity`가 나오는 곳이 있습니다.
  모든 숫자 데이터를 읽을 때 콤마(`,`), 공백, 통화기호를 제거한 뒤 숫자로 변환하는 안전한 `parseNumber()` 함수를 만들어 적용해 주세요. 또한 분모가 0일 때는 나눗셈 오류 대신 `0%`로 표시하도록 방어 코드를 넣어주세요.
  ```

### Q4. 새로운 기능을 추가해 달라고 했더니, 원래 잘 되던 화면이나 디자인이 망가졌어요!
- **원인**: AI가 전체 파일을 다시 작성하면서 기존 코드를 생략하거나 덮어썼기 때문입니다.
- **Claude Code 해결 지시문**:
  ```text
  방금 수정으로 인해 기존에 잘 작동하던 [차트/테이블/필터] 기능이 사라졌습니다.
  직전 정상 작동 상태로 되돌린 뒤, 기존 코드와 레이아웃은 절대 삭제하지 말고 내가 요청한 [추가 기능] 부분만 기존 코드에 덧붙여서 수정해 주세요.
  ```

### Q5. 차트(Chart.js)가 화면 아래로 끝없이 길어지거나 겹쳐서 깨져요!
- **원인**:1) Chart.js 캔버스 부모 박스에 고정 높이(`height`)가 없거나, 2) 필터를 바꿀 때 기존 차트 객체를 파괴(`chart.destroy()`)하지 않고 덧그렸기 때문입니다.
- **Claude Code 해결 지시문**:
  ```text
  차트가 화면 아래로 계속 늘어나거나 필터를 바꿀 때 이전 차트와 겹칩니다.
  1) `<canvas>`를 감싸는 `div`에 고정 높이(`h-72` 또는 `height: 300px`)와 `relative` 속성을 지정해 주세요.
  2) 데이터를 새로 그리기 전에 기존 차트 인스턴스가 있으면 반드시 `.destroy()`를 먼저 호출한 뒤 새로 그리도록 수정해 주세요.
  ```

### Q6. Q&A 채널에 질문할 때 어떻게 올리면 가장 빨리 해결되나요?
- **질문 3요소 양식**:
  1. **내 과제 한 줄 소개**: (예: 마케팅 채널별 ROI 분석 대시보드)
  2. **하려던 동작 & 입력한 프롬프트**: (예: 날짜 필터를 추가해 달라고 요청함)
  3. **화면 캡처 + F12 콘솔창 캡처**: 크롬/엣지 브라우저에서 `F12` 키를 누른 뒤 `Console` 탭에 뜬 빨간색 에러 글씨를 복사해 올려주시면 1분 안에 정확한 해결 프롬프트를 안내해 드립니다.
